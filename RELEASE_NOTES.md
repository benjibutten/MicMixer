# What's changed

<!-- Update this list together with user-visible changes under src/. -->

- **Music downloads use a newer yt-dlp.** MicMixer now fetches yt-dlp 2026.10.26
  instead of 2026.08.19. Sites change how they serve their media every so often,
  and an older yt-dlp can stop working when they do. If you already have
  MicMixer, it picks up the new version by itself the next time you download
  something.
